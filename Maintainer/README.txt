MAINTAINER
==========

Nothing in this folder is needed by normal users. This is the build and
container tooling that produces "ECF Classification.exe" (the file at the
top level of this folder that staff actually double-click) and the optional
Docker image.

If you are here to run the tool, you don't need to open anything in this
folder -- see "HOW TO RUN.md" one level up.

If you maintain the tool, "HOW TO RUN.md" also has a "For whoever maintains
this (technical)" section at the bottom covering everything in here:
building the .exe, the Docker image, requirements files, and RUN.bat.
